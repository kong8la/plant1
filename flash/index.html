刷写 FM-1 固件

在浏览器里把 .fwsc 固件包写进 M-VAVE FM-1：选包 → 校验 → 连接 → 写入 → 设备重启后自报身份确认。 大约一分钟，走的是 FM-1 自己的 USB-MIDI 升级协议（M-UPGRADE 兼容）。

开始之前

  • 会覆盖 FM-1 当前的固件、工程、音色和采样。想留的东西先导出来。
  • 用桌面版 Chrome 或 Edge，USB 数据线直连，关掉 DAW / MIDI-OX / 其它升级页（Windows 一次只让一个程序占用端口）。
  • 写入中途断了不会变砖：设备会停在更新加载器里，插回线再点一次「写入」即可续传。
  • 上面第二个候选是 PLANT-1 M0：把浏览器版的引擎搬上真机的第一个里程碑，一个 FM 音色 + 包络 + 27 键。

日志

PLANT-1 不在这个页面上刷。它是一台跑在浏览器里的合成器（直接试玩）， 装机方式见 安装页。这一页负责的是真正的 FM-1 固件包（.fwsc）： 社区固件、官方固件，或者你从别处拿到的实验固件——只要它是 fm1-base 体系的包。 刷机协议与包解析来自 zombie-fm1-web / fm1-base， 按 MPL-2.0 使用。想回原厂：用 M-VAVE 自己的升级工具（M-UPGRADE）。
