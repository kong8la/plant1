安装 PLANT-1

把合成器装到本机，之后断网也能打开；顺手可以把 M-VAVE FM-1 接进来当键盘和旋钮。 整个过程不需要刷机，大约一分钟。

开始之前

  • 用桌面版 Chrome 或 Edge（需要 Web Audio；Firefox 也能弹，但安装体验不同）。
  • 想接 FM-1 的话：用 USB 数据线直连电脑并开机，关掉其它占用它 MIDI 端口的软件。
  • PLANT-1 是浏览器固件，不会写入 FM-1 的 flash，不会变砖，也不会动你的工程和音色。

日志

关于真机固件：PLANT-1 跑在浏览器里，所以这里的「安装」是把合成器装成本机应用， 并把 FM-1 当作控制器接入；它不会替换 FM-1 里的固件，也不需要 M-UPGRADE。 想真正刷进设备，请用 fm1-base 的 .fwsc 工具链或社区固件（Golf、fm1-dock、OG Synth）；要恢复原厂固件用 M-VAVE 自己的升级工具。
与 Kilohearts（Phase Plant）、M-VAVE（FM-1）均无隶属关系。
